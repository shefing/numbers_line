1.3 קבצי הקראה

כדי שההקראה תעבוד, צריך

  1. ליצור קובץ oga (אפשר לייצא קובץ ogg ולשנות את הסיומת ל-oga)
  2. לערוך את הקובץ ב-audacity ולסמן עליו labels, ולייצא דרך Export Labels.
  3. לשים את שני הקבצים באותה תיקייה בתוך Textit_Storage עם קונבנציות שיום כזו:
    • audio.oga
    • audio_timecodes.txt
    • **** עבור קבצי mp3 (לאייפד)
      audiomp3.mp3
      audiomp3_timecodes.txt
  4. להוסיף לעורך את השורה המפרטת את המיקום של קובץ הקול + ה-timecodes
