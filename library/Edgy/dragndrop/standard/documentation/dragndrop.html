3. Content

within the downloaded folder there is a file name content1.js which contains 2 types of data: 

  1. options: id, text, image, sound, matching baskets.
  2. conguration data: number of options, random flag, feedback appearance flag and welcome sound.
  3. final feedback has 2 options for errors removal: "automaticaly", "onUserInteraction".
   4. fade on drag, optional. fadeOnDrag: true/false.
after editing content1.js paste its content here for format avalidation
